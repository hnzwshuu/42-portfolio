# ft_printf

## Description

`ft_printf` は、C 標準ライブラリの `printf` 関数の基本的な動作を自作する課題です。
可変長引数を扱い、フォーマット文字列を解析しながら、指定された型に応じて値を標準出力へ書き出します。

この実装では、以下の変換指定子に対応しています。

- `%c`: 1 文字を出力
- `%s`: 文字列を出力
- `%p`: ポインタアドレスを 16 進数で出力
- `%d`: 10 進符号付き整数を出力
- `%i`: 10 進符号付き整数を出力
- `%u`: 10 進符号なし整数を出力
- `%x`: 小文字の 16 進数を出力
- `%X`: 大文字の 16 進数を出力
- `%%`: `%` 文字を出力

## Instructions

コンパイルするには、次のコマンドを実行します。

```sh
make
```

成功すると、静的ライブラリ `libftprintf.a` が作成されます。

オブジェクトファイルを削除する場合:

```sh
make clean
```

オブジェクトファイルと `libftprintf.a` を削除する場合:

```sh
make fclean
```

再コンパイルする場合:

```sh
make re
```

## Algorithm and Data Structures

この実装では、複雑なデータ構造は使用していません。
中心となるデータは、フォーマット文字列を指す `const char *format`、可変長引数を管理する `va_list`、出力文字数を記録する `size_t len` です。

処理の流れは次の通りです。

1. `ft_printf` が `va_start` によって可変長引数の読み取りを開始します。
2. フォーマット文字列を先頭から 1 文字ずつ走査します。
3. 通常の文字であれば `ft_putchar` でそのまま出力し、出力文字数を増やします。
4. `%` を見つけた場合は、次の文字を変換指定子として読み取ります。
5. `ft_convert_specifier` が指定子を判定し、対応する出力関数へ処理を振り分けます。
6. 各出力関数は `write` を使って標準出力へ書き込み、成功した分だけ `len` を更新します。
7. すべての文字を処理したあと `va_end` を呼び、最終的な出力文字数を返します。

整数や 16 進数の出力には再帰を使用しています。
たとえば 10 進整数では、数値を 10 で割りながら上位桁を先に出力し、最後に現在の桁を出力します。
16 進数も同様に、16 で割ることで上位桁から順に出力します。

このアルゴリズムを選んだ理由は、桁を一時的な文字列バッファに保存せず、正しい順序で直接出力できるためです。
固定長配列や動的メモリ確保を使わないため、実装が単純で、メモリ管理のリスクも低くなります。
また、各出力関数が `size_t *len` を受け取って文字数を直接更新することで、`printf` と同じように出力済み文字数を返せるようにしています。

ポインタ出力では、`void *` を `uintptr_t` に変換してから 16 進数として処理します。
`uintptr_t` はポインタ値を整数として安全に保持するための型であり、アドレスを数値として扱う用途に適しています。
`NULL` ポインタの場合は、通常のアドレス表記ではなく `(nil)` を出力します。

エラー処理として、`write` が `-1` を返した場合は各関数も `-1` を返し、呼び出し元へ失敗を伝播します。
これにより、出力途中でエラーが発生した場合にも検知できる構造になっています。
